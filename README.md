# Crowdfunding Success Prediction

AI for Business and Society — SKEMA BBA4 — Thibault & Khoubeybe

Predicting whether a Kickstarter campaign will reach its funding goal,
*before launch*, using machine learning.

## Setup

This project needs Python with `pandas`, `numpy`, `scikit-learn`,
`xgboost`, `matplotlib`, `streamlit`, `plotly`, and `nltk` installed
(see `requirements.txt`).

If you have several Python installations on your machine (common on Mac),
make sure you install the packages on the **same one** you use to run the
scripts. Check which one you're using with:

```bash
which python3
python3 -m pip install -r requirements.txt
```

`01_clean_data.py` also needs NLTK's VADER sentiment lexicon (one-time
download):

```bash
python3 -c "import nltk; nltk.download('vader_lexicon')"
```

## Project structure

```
data/
  raw/kickstarter_full_campaigns.csv   <- original dataset (Kaggle, 694,062 campaigns)
  Kickstarter_clean.csv                <- generated by 01_clean_data.py
  eda_*.png                            <- generated by 02_eda.py
  model_comparison.csv                 <- generated by 03_modeling.py
  confusion_matrix.png                 <- generated by 04_tuning.py
  feature_importance.png               <- generated by 04_tuning.py
  model.pkl                            <- trained model + metadata, generated by 04_tuning.py
scripts/
  01_clean_data.py    <- filters, cleans, and engineers features
  02_eda.py            <- exploratory analysis + charts
  03_modeling.py        <- trains and compares 5 models
  04_tuning.py           <- tunes XGBoost, confusion matrix, feature importance
app.py                  <- interactive demo (Streamlit)
```

## Running the pipeline

Run the scripts **in order** — each one reads the file the previous one
produced:

```bash
cd kickstarter-project
python3 scripts/01_clean_data.py
python3 scripts/02_eda.py
python3 scripts/03_modeling.py
python3 scripts/04_tuning.py
```

`04_tuning.py` takes a few minutes (hyperparameter search), and must run
at least once before the demo app below (it saves `data/model.pkl`).

## Interactive demo

Once `04_tuning.py` has run (so `data/model.pkl` exists):

```bash
streamlit run app.py
```

This opens a browser page where you enter a planned campaign's details
(goal, category, country, duration, tagline, etc.) and get a predicted
success probability — the "Expected Application" from our proposal, made
usable. Includes a success-probability gauge, a goal sensitivity curve, a
3D globe showing the launch country, a category benchmark chart, and a
sentiment/keyword analysis of the tagline.

## Method summary

- **Data**: Kaggle "Kickstarter Full Campaigns" dataset, 694,062 campaigns
  (2009-2026). Filtered to finished campaigns only (successful/failed),
  598,740 rows after cleaning.
- **Target**: did the campaign reach its funding goal (1) or not (0)?
- **Features**: only information known *before* launch (goal, category,
  country, duration, launch month, staff pick, etc.). `backers_count` and
  `usd_pledged` are deliberately excluded — they're only known once a
  campaign is already running, so using them would be data leakage.
- **NLP features**: VADER sentiment score + presence of 9 "vague pitch"
  keywords ("want", "create", "people"...) found, via word-frequency
  analysis, to be more common in *failed* campaigns' taglines. Words tied
  to a specific product type (e.g. "tabletop", "album") were excluded —
  they just re-encode `category`, which the model already has. Honest
  result: these features gave a small lift (+0.2 points accuracy); most
  individually rank mid-table in feature importance, and the aggregate
  sentiment score ranks near the bottom (177/191) — campaign success
  looks driven more by structural factors (goal, category, staff pick)
  than by tagline tone.
- **Models compared**: Logistic Regression (baseline), Decision Tree,
  Random Forest, AdaBoost, XGBoost. XGBoost performs best and is the
  final choice, confirming the hypothesis from our proposal (based on a
  reference GitHub project we verified independently).
